# 雾镜 · Fog Mirror

在浏览器里玩的「浴室雾镜」：电脑摄像头的画面像一面镜子，对着镜头哈气就会起雾，捏住拇指和食指就能在雾上擦出字来。

**在线玩：https://jamie-xyz.github.io/wJing/**（注意 J 是大写）

用 Chrome 或 Safari 打开，点「开始」，允许使用摄像头。

## 怎么玩

- **哈气起雾**：脸靠近镜头，张嘴「哈——」，雾从嘴边慢慢扩散开，哈得越久雾越大
- **擦雾**：捏住拇指和食指在空中移动；也可以在小气泡里换成「竖起食指」（伸出中指就停）
- **用手掌擦淡**：手掌张开在雾上慢慢抹（或者捂着不动），手掌下面那一片雾慢慢变淡，快慢在小气泡里调；按 X 一下清掉所有雾
- **反转**：写完字点「反转」或按 I，字变成雾做的、别的地方擦干净，适合和字一起合照
- **设置**：底部中间的小圆圈里可以调雾的浓度、消散速度、擦痕粗细、哈气灵敏度，还有辅助书写、水珠开关
- **快捷键**：S 截屏 · R 录屏（再按一次停）· I 反转 · X 清雾 · D 调试面板

## 隐私

摄像头的画面只在你自己的电脑上处理，不会上传到任何地方。
认手和认脸用的是 Google 的 [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/guide)，打开网页时会从网上下载识别模型（大约 12 MB）。

整个网页就是一个 `index.html` 文件，不需要服务器。
